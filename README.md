
# Text to Speech Application

## Project Overview
A Python application that converts written text into spoken audio.

## Features
- Convert text into speech.
- Save speech as a WAV audio file.
- Adjust speech speed and volume.
- Simple menu-driven application.
- Offline text-to-speech conversion.

## Technologies Used
- Python
- pyttsx3

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```
